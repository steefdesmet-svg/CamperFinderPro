# CamperFinder Pro 1.0

Android-app voor motorhomereizigers om camperplaatsen in de omgeving te vinden.

## Installeren zonder Android Studio

1. Open bovenaan het tabblad **Actions**.
2. Open de meest recente geslaagde uitvoering van **Bouw CamperFinder Pro APK**.
3. Download onder **Artifacts** het bestand **CamperFinderPro-1.0**.
4. Pak het gedownloade ZIP-bestand uit.
5. Open `CamperFinderPro-1.0.apk` op de Android-tablet en installeer het.

Bij de eerste installatie kan Android vragen om installatie vanuit deze bron toe te staan.

## Functies

- GPS-locatie en OpenStreetMap-kaart
- Instelbare zoekradius
- Camperplaatsen zoeken via OpenStreetMap/Overpass
- Sorteren volgens afstand
- Details over water, elektriciteit, loospunt, capaciteit en tarief indien beschikbaar
- Rechtstreeks navigeren met Google Maps
